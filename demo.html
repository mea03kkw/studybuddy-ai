🚀 Run the Real Application
To run the actual Flask application:
# 1. Clone repository
git clone https://github.com/mea03kkw/studybuddy-ai.git
cd studybuddy-ai

# 2. Create virtual environment
python -m venv venv
venv\Scripts\activate  # Windows
# or source venv/bin/activate  # Mac/Linux

# 3. Install dependencies
pip install -r requirements.txt

# 4. Install Ollama (from ollama.ai)
# 5. Pull model: ollama pull phi:2.7b

# 6. Run Ollama in separate terminal
ollama serve

# 7. Run Flask app
python app.py

# 8. Open http://localhost:5000
